# AV Risk Scenario Analysis Bundle

This bundle includes:
- Simulated dataset of ride experiences with scenario and sentiment labels
- Chart visualizations comparing Waymo and Uber responses
- Template for scraping Twitter, Reddit, and Yelp (API keys required)
- Instructions to run and analyze data

To run:
1. Install dependencies: pip install pandas textblob matplotlib seaborn
2. Load 'simulated_sentiment_scenario_data.csv' in your analysis script
3. Review the charts or extend the scraper templates
